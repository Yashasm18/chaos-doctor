How it works
Two open-weight models take turns. agentic-chaos does the breaking and the judging. Everything else is plain, testable code.

    

      

        

          your agent
          open-weight model · Doctor
          open-weight model · Attacker
          deterministic code
        

        
      

      

      

    

    

      
1-2
Break and score
Faults from agentic-chaos hit the model client and tools. Its contracts plus the agent's own check give a pass rate per attack.

      
3
Diagnose
The Doctor (Qwen3) reads the failure and the code and answers in strict JSON: root cause, function, one recipe from a fixed menu, parameters.

      
4-5
Patch and verify
An ast patcher adds one guard decorator, so the code always parses. Re-scan: keep the patch if the score rises, roll back if not.

      
6
Attack again
The Attacker (Qwen3) reads the patched code and picks the next attack, writing its own prompt-injection payloads.

      
✓
Why a small model works
Both AIs choose from fixed, executable menus. They never write free-form code, and every change is a reviewable diff.

      
↗
Fits the ecosystem
Ships as an Agent Skill, a CLI, a CI gate (--min-score) and AIOS v0.4 Run export for the DeepAgentLabs tools.

Run it yourself
Python 3.10+. No model needed for --offline; add Ollama for the AI Doctor.

    

      

        
terminal


git clone https://github.com/Yashasm18/chaos-doctor.git
cd chaos-doctor
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
chaos-doctor battle examples/shop_agent/agent.py --offline

      

      

        
with the open-weight model


ollama pull qwen3:4b
export CHAOS_DOCTOR_MODEL=qwen3:4b
chaos-doctor battle examples/shop_agent/agent.py
chaos-doctor scan examples/shop_agent/agent.py --min-score 70
