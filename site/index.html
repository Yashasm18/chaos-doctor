How it works

  1. AttackFaults from agentic-chaos hit the agent: model timeouts, 429 storms, tool crashes, garbled replies, too-long prompts, and prompt injections the Attacker writes itself.
  2. ScoreEvery run is judged by agentic-chaos contracts (no crash, bounded retries) plus the agent's own answer check. Score = average pass rate, 0 to 100.
  3. DiagnoseThe Doctor model reads the failure and the source and answers in strict JSON: root cause, which function, which fix recipe, which parameters.
  4. Patch & verifyOne guard decorator is added with Python's ast, so the code always parses. The agent is re-tested and a patch that doesn't help is rolled back.

Both AIs choose from fixed, executable menus, which is what makes a small model reliable. Open-weight models: Qwen3-8B / Qwen3-4B (Apache-2.0) via Ollama.
